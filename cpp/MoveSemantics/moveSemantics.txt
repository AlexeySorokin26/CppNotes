         expression
         /        \
     glvalue     rvalue
     /     \     /    \
 lvalue    xvalue    prvalue
 prvalue — «чистое» временное значение: 42, x + 1, std::string("a").
 xvalue — объект с идентичностью, ресурсы которого можно забрать: std::move(x), static_cast<T&&>(x).
 lvalue — x, *p, a[i], вызов функции, возвращающей T&.


Вид value относится не к типу а к выражению 
Не бывает lvalue типа или rvalue типа 
int сам по себе ни lvalue ни ralvue 
У любого выражения есть два свойства 
    его тип и его категория value 

Компилятор для каждого выражения определяет две вещи: тип и категория значения (value)
    Тип отвечает на вопрос «что это за значение»: int, std::string, double*. От типа зависят допустимые операции и размер.
    Категория значения (lvalue / xvalue / prvalue) отвечает на вопрос «как с этим значением можно обращаться». Есть ли у него идентичность (адрес, время жизни дольше выражения)? Можно ли забрать его ресурсы (переместить)?
std::string s = "abc";
s              // тип std::string, категория lvalue
std::move(s)   // тип std::string, категория xvalue

Каждое выражение в C++ характеризуется типом (какое у него значение) и категорией значения (есть ли у него идентичность и можно ли его перемещать). 
lvalue — выражение с идентичностью, которое нельзя перемещать. xvalue — с идентичностью, но перемещать можно. prvalue — без идентичности, временное значение.

int x  = 1;              // выражение: 1, тип int, prvalue
int& rx = x;             // выражение: x, тип int, lvalue
int&& r = 5;             // выражение: 5, тип int, prvalue
int&& r2 = r;            // ce: r — lvalue (у него есть имя), хотя объявлен как int&&
x = 10;                  // выражение: x = 10, тип int, lvalue (x — lvalue, 10 — prvalue)
r = 10;                  // выражение: r = 10, тип int, lvalue (r — lvalue, 10 — prvalue)
int z = 10;              // выражение: 10, тип int, prvalue
rx = z;                  // выражение: rx = z, тип int, lvalue (rx — lvalue, z — lvalue)
int&& m = std::move(x);  // выражение: std::move(x), тип int, xvalue
int w = std::move(z);    // выражение: std::move(z), тип int, xvalue
