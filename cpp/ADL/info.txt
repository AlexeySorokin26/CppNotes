Поиск Кенинга (ADL)
    Argument dependent name lookup

ADL (Argument-Dependent Lookup, он же «поиск Кёнига» по имени Эндрю Кёнига) 
— это правило, по которому при неквалифицированном вызове функции компилятор ищет её имя 
не только в текущей и охватывающих областях видимости, 
но ещё и в пространствах имён, к которым относятся типы аргументов 
(так называемые «ассоциированные пространства имён»).

Пример
    sort(v.begin(), v.end())

    v.begin()/v.end() возвращают итератор std::vector<T>::iterator, 
    а его тип живёт в пространстве std
    Поэтому при вызове sort(...) без квалификации 
    компилятор добавляет std в множество для поиска и находит std::sort. 
    Именно за счёт ADL можно писать просто sort(...), а не std::sort(...).

Почему это «крайне полезно для операторов»
namespace long_nums{
    struct lint{...};
    lint operator+(lint& const&, lint const&);
}

without ADL 
auto x = long_nums::operator+(i, 5);

with ADL
long_nums::lint i = 42;
auto x = i + 5;

Строка auto x = i + 5; — это, с точки зрения компилятора, 
вызов operator+(i, 5). То есть у этого «вызова» два аргумента:

i — тип long_numbers::lint
5 — тип int

у long_numbers::lint ассоциированное пространство — long_numbers (там объявлен тип)

По ADL компилятор ищет operator+ в ассоциированных пространствах операндов, 
а туда входит long_nums, — и находит нужный оператор автоматически.
