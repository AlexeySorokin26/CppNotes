Да, паттерн одинаковый для всех контейнеров STL — это не специфика map/multimap, а общая идиома.
Общее правило

insert — принимает готовый объект T (копирует или перемещает его в контейнер)
emplace — принимает аргументы конструктора T и строит объект прямо в памяти контейнера, без промежуточного временного объекта

insert vs emplace — это про КОНСТРУИРОВАНИЕ, а не про API-предпочтение

insert принимает уже готовый объект (или что-то неявно конвертируемое в него) и копирует/перемещает его в контейнер.
emplace принимает аргументы конструктора и строит объект прямо в памяти контейнера, без промежуточного временного объекта.

m.insert(std::pair<std::string, int>("a", 1)); 
m.emplace("a", 1);  

std::vector<std::string> v;

v.push_back(std::string("hello"));  // создали временный string, потом переместили
v.emplace_back("hello");            // string сконструирован сразу в буфере вектора, из "hello"

v.insert(v.begin(), std::string("x")); // insert для vector = "вставить готовый объект в позицию"
v.emplace(v.begin(), "x");             // сконструировать на месте по итератору\


std::set<std::string> s;
s.insert(std::string("a"));  // готовый объект
s.emplace("a");              // строим string("a") прямо в узле дерева
