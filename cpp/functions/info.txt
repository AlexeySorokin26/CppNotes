Почему аргументы по умолчанию пишутся только в объявлении 

Аргумент по умолчанию — это по сути синтаксический сахар, 
который компилятор подставляет в точке вызова, а не внутри функции. 
Когда ты пишешь f() при объявлении void f(int x = 5), 
компилятор превращает это в f(5) прямо там, где стоит вызов. 
Само тело функции ничего не знает о дефолте — оно просто получает готовый int и не различает, 
пришёл он явно или был подставлен.

Отсюда главное следствие: значение по умолчанию должно быть видно в каждой точке вызова. 
А вызовы находятся в тех единицах трансляции, которые подключают заголовок, — не в твоём .cpp.

трого говоря, аргумент по умолчанию можно написать и в объявлении, 
и в определении — язык это не запрещает. Настоящее ограничение другое: 
для каждого параметра значение по умолчанию можно задать только один раз в пределах области видимости.
