Ranges c++20 
		std::ranges — это слой поверх классических алгоритмов из <algorithm>, появившийся в C++20. 
		Идея простая: классический std::find принимает пару итераторов (begin, end), 
		а std::ranges::find принимает сам контейнер как единое целое (range — это что угодно, у чего есть begin()/end()).

Можно пропускать члены — то, что не указано, инициализируется значением по умолчанию (для min/max/decimals в полях типа Text они просто остаются дефолтными, потому что не нужны).
Меньше шансов ошибиться, если в структуре много полей одного типа (как тут несколько QString подряд).
Если мы пропустим то значение поставится дефолтное или то что будет в самой стркутуре

rule of zero is better than rule of 5 

struct Chart {
    std::string title;
    std::vector<int> data;
    int sheetIndex = 0;

    // Рукописный move-конструктор — три способа всё испортить:
    Chart(Chart&& o) noexcept
        : title(o.title)              // (1) забыл std::move  -> КОПИЯ
        , data(std::move(o.data))     //     ок
    {}                                // (2) забыл поле data   -> default (пусто)
                                      // (3) забыл sheetIndex  -> остаётся 0, не из o
};

= default означает «компилятор, сгенерируй эту функцию сам». Но в rule of zero вся идея в том, что ты вообще ничего не объявляешь — и компилятор генерирует все спец-функции автоматически. 
Писать = default для каждой из них — это просто многословный способ получить ровно то же самое, что и при полном молчании. Лишний шум, который противоречит названию «правило нуля».
