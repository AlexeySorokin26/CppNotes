Существует несколько видов паралелизма
1. Data parallelism 
    процессор выполняет одни и теже операции на разных кусках данных 
        пример добавить 1 ко всем пикселям
2. Task parallelism
    задачки выполняются на разных процессорах и они никак не связаны друг с другом 
        пример приготовление ужина кто-то режет марковь кто-то картошку кто-то жарит мясо
3. Pipeline parallelism
    тут задачки зависят друг от друга и процессоры могут ждать когда один закончит одну задачку 
        пример кто-то моет яблоко кто-то его чистит кто-то его ест все зависят друг от друга но могут делать свои задачи параллельно как-то получат возможность 


Основной элемент в GPU это SM straming multiprocessor 
    Сам по себе GPU не отвечает за вычисления аримфмитические и логические этим занимается SMs который включает в себе множество CUDA cores 

    Примерная схема GPU
    GPU 
        Global memory
        L2 cache
        SM .. SM
        SM .. SM
        ..    ..
        SM .. SM
    Примерная схема SM
    SM
        Shared memory/L1
        Registers
        Control
        Cuda core .. Cuda core
        Cuda core .. Cuda core
        ..           .. 
        Cuda core .. Cuda core
    CPU
        L2
        Core        Core
            Control     Cotrol
            ALU         ALU
            L1          L1
        ..          ..
        Core        Core
            Control     Cotrol
            ALU         ALU
            L1          L1
