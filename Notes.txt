1. Управление памятью и указатели
std::shared_ptr — указатель с подсчетом ссылок.

std::unique_ptr — исключительное владение (замена auto_ptr).

std::weak_ptr — решение проблемы циклических ссылок.

nullptr — типобезопасный нулевой указатель (вместо NULL и 0).

2. Вывод типов и инициализация
auto — автоматическое выведение типа переменной.

decltype — получение типа выражения во время компиляции.

Uniform initialization — унифицированная инициализация через {}.

initializer_list — работа со списками инициализации.

3. Семантика перемещения (Move Semantics)
Rvalue references (&&) — ссылки на временные объекты.

Move constructor / Move assignment operator.

std::move — приведение к rvalue.

std::forward — идеальная передача (perfect forwarding).

4. Лямбда-выражения
Синтаксис: [capture](params) -> ret { body }.

Типы захвата: по значению [=], по ссылке [&], индивидуально.

mutable лямбды.

Преобразование лямбды в std::function.

5. Умные возможности компилятора
= default — явное использование стандартной реализации (конструкторы, операторы).

= delete — запрет методов (например, копирования).

override — явное указание переопределения виртуального метода.

final — запрет переопределения/наследования.

6. Многопоточность (Threading)
std::thread — запуск потоков.

std::mutex, std::lock_guard, std::unique_lock.

std::atomic — атомарные операции.

std::async, std::future, std::promise — асинхронные задачи.

Thread-local storage (thread_local).

7. Алгоритмы и контейнеры (новинки)
std::unordered_set / std::unordered_map — хеш-таблицы.

std::array — статический массив с STL-интерфейсом.

std::forward_list — односвязный список.

Алгоритмы: std::all_of, std::any_of, std::none_of, std::copy_if, std::move (алгоритм).

8. Прочие важные возможности
Range-based for — цикл по диапазону: for (auto& x : container).

constexpr — вычисления на этапе компиляции.

static_assert — проверки во время компиляции.

long long — 64-битный тип.

Алиасы типов (using) — читаемая замена typedef.

Делегирующие конструкторы — вызов конструктора из конструктора.

Наследование конструкторов — using Base::Base.

Пользовательские литералы — например, "hello"_s.

9. Библиотечные улучшения
std::chrono — работа со временем (длительности, моменты, часы).

std::tuple — гетерогенная коллекция фиксированного размера.

std::regex — регулярные выражения.

Случайные числа: std::random_device, std::mt19937, распределения.

std::bind и std::function (хоть и появились в C++11, часто используются).
