## CDF — что это и зачем

### Задача
У нас 3D-картинка активности: в каждом вокселе своё число — насколько
ярко он «светит» (сколько позитронов там рождается). Нужно разыгрывать
события так, чтобы **яркий воксель выбирался чаще**, тусклый — реже,
строго пропорционально активности.

### Шаг 1. Вероятности
Берём активности и делим каждую на общую сумму — получаем доли (вероятности),
которые в сумме дают 1.

```
воксель:      0     1     2     3
активность:   10    50    10    30     (сумма = 100)
вероятность:  0.1   0.5   0.1   0.3    (каждая / 100, сумма = 1)
```

Это **PDF** (probability density / распределение): «шанс, что событие
именно в этом вокселе».

### Шаг 2. CDF = нарастающая сумма вероятностей
**CDF** (cumulative distribution function, функция распределения) —
это префиксная сумма вероятностей: «шанс, что событие в вокселе ≤ i».

```
вероятность:  0.1   0.5   0.1   0.3
CDF:          0.1   0.6   0.7   1.0    ← это Scan по вероятностям
                                  ^
                                  всегда заканчивается на 1
```

Вот зачем раньше был Scan: CDF — это и есть scan (нарастающая сумма).

### Шаг 3. Как по CDF выбрать воксель (главный трюк)
CDF делит отрезок [0, 1) на «коридоры», ширина каждого = его вероятность:

```
0.0        0.1               0.6     0.7          1.0
 |----------|-----------------|-------|------------|
   воксель0     воксель1       вокс2    воксель3
   шир.0.1      шир.0.5        0.1      0.3
```

Разыгрываем так:
1. бросаем случайное число r равномерно в [0, 1)
2. смотрим, в какой коридор оно попало → это и есть выбранный воксель

Поскольку ширина коридора = вероятность вокселя, большой коридор
(воксель 1, ширина 0.5) ловит r в 5 раз чаще мелкого — ровно то,
что нужно. Поиск коридора — это бинарный поиск «первый CDF ≥ r»
(`std::lower_bound`).

### Связка с предыдущими разделами
- **нормировка на сумму** (деление на 100) → вероятности
- **Scan** по вероятностям → CDF
- **ClampNeg** перед этим → чтобы отрицательная активность не портила сумму

То есть `BuildVoxelCdf` целиком = ClampNeg → сумма → нормировка → и у нас CDF,
по которой `PickVoxel` бросает r и находит воксель.
